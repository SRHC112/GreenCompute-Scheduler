# 第三方依赖与许可声明

本项目为参赛作品源码，以下列出**运行路径上实际使用**与**设计中参照**的全部第三方组件。

## 一、运行时强制依赖

| 名称 | 版本约束 | 许可 | 用途 | 是否进入评测数值 |
|---|---|---|---|---|
| PyYAML | >=6.0,<7.0 | MIT License | 解析 `knowledge/ningxia_cluster.yaml` 领域知识包 | 否（仅负责读入） |
| Python 标准库 | 3.10+ | PSF License | dataclasses / urllib / json / csv / http.server / unittest / random / statistics | — |

**除上表外，本项目不依赖任何其他第三方包。**
操作台（`app/server.py`）、看板（`console.html`）、对照实验（`evaluation/run_eval.py`）
全部基于标准库实现，不引用任何 CDN 资源，断网环境可完整演示。

## 二、设计参照（未进入运行路径）

| 名称 | 许可 | 参照了什么 | 本项目的差异 |
|---|---|---|---|
| AgentScope 2.0 | Apache-2.0 | 角色化 Agent 建模、角色卡（Role Card）、Agent 间消息传递、结构化输出约束 | 本项目自研七角色与八状态机；DAG 拓扑分层、返工边、定向返工、rubric 六维评分、预算熔断均为自研，未复制其源码 |
| DeerFlow 2.0 | Apache-2.0 | 长程任务的「计划—执行—观察—重规划」范式、子 Agent 委派与进度流式回传 | 本项目把长程 Harness 收敛为**确定性可复算**的垂直调度闭环：数值全部由规则模块计算，模型只做叙述与语义 Judge；对照实验中的 G-C 组是对该类通用范式的**行为模拟**，非其真实运行结果 |
| DeepEval | Apache-2.0 | 评测维度打分与断言（assertion）思想 | 本项目自研 `gcs/reflect.py` 六维 rubric（硬约束 30 / 数值一致性 20 / 证据强度 20 / 任务覆盖度 15 / 结构合规 10 / 成本效率 5）与缺陷归因逻辑 |
| LangGraph | MIT License | 有状态图编排与条件边（conditional edge） | 本项目自研八状态机与返工边激活策略；不依赖任何图框架，避免运行时依赖膨胀 |

> 上述组件均**未复制源码、未打包进本仓库**，仅在方案书中作为方法论对照引用并注明出处与许可。
> 若后续提交要求补充引用清单，可直接将本表附在方案书附录。

## 三、数据与素材声明

| 类别 | 来源 | 处理方式 |
|---|---|---|
| 峰谷分时电价 | 公开分时电价代表性取值 | 写在知识包 `tariff` / 各池 `price` 段，**标注为代表性取值**，生产接入时替换为电网实时接口，字段结构不变 |
| 绿电出力曲线 | 依据宁夏以光伏为主、风光互补的公开特征构造 | `green_share_by_hour` 24 点数组，注释中明确「用于演示与评测」，非官方实测曲线 |
| 电网排放因子 | 西北区域电网代表值 0.581 kgCO₂e/kWh | 标注为代表值 |
| 资源池参数（PUE、卡数、单机功率、折旧摊销） | 公开机架与能效常识性取值 | 标注为演示参数 |
| 作业画像 | 按任务类型的典型资源需求构造 | `job_profiles`，可版本化替换 |
| 对照实验数据 | **全部由本项目自研模拟器生成** | 未使用任何第三方数据集，不存在数据来源合规风险 |
