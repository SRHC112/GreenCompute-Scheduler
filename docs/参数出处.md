# 参数出处

本文档列出知识包 `knowledge/ningxia_cluster.yaml`（版本 `nx-2026.12`）中每个关键参数的取值、公开来源、可信度与口径说明。机器可校验项见 `evaluation/trace_fit.py`；重跑校验命令：

```bash
python evaluation\trace_fit.py
```

**原则**：任何未在此表列出的「经验常数」都不应出现在调度代码里；若生产环境需要替换，只需更新知识包 YAML 并升级 `version`，无需改代码。

## 六、CI 校验项

`evaluation/trace_fit.py` 执行四项硬断言，全部通过才算知识包版本有效：

1. **分时电价时段对齐**：24 小时全部与公开口径一致（0 个不匹配）。
2. **峰谷浮动比例核对**：三个资源池均满足 peak = flat × 1.6、valley = flat × 0.6（容差 2%）。
3. **电网排放因子核对**：`grid_carbon_factor == 0.6773`（公告〔2024〕第 10 号西北区域电网因子）。
4. **绿电曲线拟合**：知识包曲线与公开装机结构重构的参照曲线皮尔逊相关系数 ≥ 0.85。
