4. 确认同种子下指标完全复现，评审现场可离线复现。
5. 确认对照实验（G-A ~ G-E2 × 3 种子）产出可用于答辩的证据材料。

## 四、测试策略与方法

1. **确定性测试**：所有作业流由 `(seed, 序号)` 决定，同种子必得同一批作业与同一指标，用于复现性验证。
2. **对照组法**：六组配置（G-A ~ G-E2）共用同一模拟器数据、同一知识包版本、同一评测脚本，只改 Policy 开关。
3. **反事实扫描**：权重旋钮（wait_scale）、返工阈值、绿电权重逐档扫描，观察指标变化方向。
4. **机器校验**：trace_fit.py 对照公开口径，24 小时时段 0 不匹配、峰谷比容差 2%、排放因子精确相等、绿电曲线相关系数 ≥ 0.85。
5. **离线降级**：不配置 LLM 环境变量，系统退化为离线确定性模板，指标数值不变。
