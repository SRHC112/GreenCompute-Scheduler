# 初赛演示视频脚本（约 4 分钟）

**用途**：2026 第五届「未来杯」赛题一「Agent 编排创新应用」初赛必交件之「演示视频（必选）」  
**官方要求**：3-5 分钟，完整展示**平台界面、Agent 编排过程、任务调度执行、结果验证与反馈闭环**的关键操作  
**录制对象**：本仓库 `main` 分支最新提交（录制前执行 `git log -1` 记录版本号即可复现）  
**成片规格**：1920×1080 / 30fps / H.264 MP4，音量 −6 dB 峰值，字幕硬压或 SRT 外挂均可  
**旁白语速**：按 260 字/分钟（自然照读语速）设计，全文约 975 字，开口约 3 分 45 秒；分镜合计 4 分 00 秒，留 15 秒画面停留与呼吸（官方要求 3-5 分钟，4:00 居中安全）

## 三、旁白逐字稿（可直接照读）

> **口径提示（不读入旁白）**：本稿出现两组 rubric 数字，对应不同对象，均经实测核对，不得互换或叠加——①【单次 demo 运行】`gcs.demo --jobs 30 --seed 20261111` 的 `artifact.json`：首轮 70 分 → 返工 2 轮后 **100 分**（关掉闭环的 `--policy no_reflect` 对照为 1 轮、70 分）；②【六组统计评测】`evaluation/summary.json`（80 作业 × 3 种子）：G-A 基线 **70** → G-D 本方案 **80**（三个种子均值）。录制时按镜头所属对象引用，勿混用。

> 说明：`｜` 表示换气停顿，`**粗体**` 为必须念准的数字。

**【00:00-00:12 封面】**

绿算调度，面向东数西算宁夏枢纽的算力作业多智能体编排平台。｜四分钟，完整演示编排、调度、验证与反馈闭环。

**【00:12-00:35 问题陈述】**

先看问题。｜难点不在算得快，而在**什么时候算、用哪张卡、算错了谁兜底**。｜风光电随时波动，电价与 PUE 随之跳动；现有框架大多是脚本化流水线，调度靠先来先服务，结果没有自动校验。｜我们针对的正是编排、调度、验证。

**【00:35-01:05 平台界面】**

这是平台的本地操作台，一条命令启动，不依赖任何第三方服务。｜界面四块：任务发起，自然语言描述作业；DAG 拓扑，拆成有依赖的图；运行轨迹，记录每个 Agent 的动作；评测看板，直接读评测结果。｜四块对应官方要求的四个环节，逐块看。

**【01:05-01:50 Agent 编排】**

编排层定义**七个角色**：需求解析、知识检索、调度规划、执行、验证、返工、报告。｜每个角色有角色卡、工具白名单和失败出口——错误不会无声传下去。｜角色间不走自由对话，而是走一张 DAG 和一套**八状态机**：待命、就绪、执行、校验、返工、通过、阻塞、终止。｜看这张拓扑图：并行分支同时跑，条件不满足走回退边，不整条流水线重来。｜整套编排代码化，可版本管理、可复现，不是拖拽黑盒。

**【01:50-02:35 任务调度执行】**

现在跑一次完整编排：三十个作业，固定随机种子。｜终端四个关键指标：SLA 达成率 **100%**，单位成本约 **2.38 元每 GPU 小时**，平均绿电占比约 **73.1%**，碳排约 **26.5 公斤**；返工 **2 轮**，rubric 从 70 分收敛到满分 **100**。｜同样的种子和参数，必然得到同样的数字，可复现。｜看板左边是时间轴排布，右边是指标变化。｜调度器在时延、成本、绿电之间找可解释的折中，不做单一目标最优。

**【02:35-03:10 结果验证与反馈闭环】**

验证是花力气最多的地方。｜五层验证器：结构、约束、数值复算、交叉比对、rubric 评分；原则一句：**能用规则判定的，绝不交给模型判定**。｜校验不通过触发定向返工，只重跑出问题的那一段。｜看这条记录：L3-SLA 未达成，归因时长估计偏低，第二轮修复——rubric 从 **70** 拉到 **100**，SLA 从 **96.7%** 回到 **100%**。

**【03:10-03:40 量化对照】**

增量来自**六组对照**，每组三个种子、八十个作业。｜对比先来先服务：成本降 **18.4%**，碳排降 **13.1%**，绿电窗口 31.9% 升到 **37.6%**，rubric 70 到 **80**。｜代价是 SLA 从 100% 降到 **99.2%**，如实放出。｜消融划出边界：饱和规模下闭环无增益；中小规模有可修复缺陷时，就停在 70 分。

**【03:40-04:00 收尾】**

代码全部开源，Apache-2.0，零第三方运行时依赖，一条命令完成环境检查与安装。｜绿算调度，让每一度绿电用在正确的时间、正确的卡上。谢谢。
