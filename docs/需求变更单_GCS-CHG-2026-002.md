## 二、影响评估

- **架构影响**：不引入第三方框架、JWT、数据库、会话持久化、用户注册/登录/RBAC、TLS；鉴权全部用 Python 标准库实现，符合 SRS §3.5「零依赖运行 + 可复现」；与 GCS-CHG-2026-001「本期零依赖单机形态」不冲突，鉴权属同一形态内的入口防护，不改变分阶段策略。
- **数据影响**：`evaluation/results.csv`（18 行）、`summary.json`（六组）、`summary.md`、`eval_report.html`、参数扫描与置信区间 JSON 全部重算；所有引用旧数字（2.854→2.422、−15.1%、rubric 70→90 等）的方案书、PPT、白皮书、README、测试报告、复盘记录、演示脚本需同步。
- **测试影响**：74 项既有测试保持全绿；新增 `tests/test_auth.py`、`tests/test_server.py` 共 35 项，合计 109 项全绿；覆盖率门禁 `gcs/` ≥70% 不变；CI 的 `curl -fsS /` 探测因公开只读 GET 放行而零改动。
- **文档影响**：本变更单、差异及处理方式记录、流程基线符合性记录、闭环确认清单、竞赛符合性对照、参赛提交_文件清单（包外）同步登记。
- **回退**：`GCS_AUTH_MODE=off` 可一键回到已定稿版本行为；评测数据可用 git 历史回退。
