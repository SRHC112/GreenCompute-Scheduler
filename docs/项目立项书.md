# 项目立项书

**项目名称**：绿算调度 GreenCompute-Scheduler — 面向宁夏（中卫—银川）算力枢纽的多智能体算力调度编排系统
**文档编号**：GCS-INIT-2026-001　**版本**：V1.0　**日期**：2026-11-12　**状态**：已批准（A-02）

## 一、一句话问题

把「一批算力作业交给谁跑、什么时候跑、跑在哪个资源池」从人工拍板升级为**七角色、八状态、可定向返工**的多智能体编排，使决策可解释、缺陷可归因、结果可复现。
